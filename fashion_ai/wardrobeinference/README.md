# Wardrobe Inference and Color Extraction

Builds a private wardrobe database index from detected items (using either YOLOv11 or OWL-ViT results) and extracts dominant colors from crops of these detections.

## Features

- **YOLO Pathway**:
  - Run inference on a photo using the trained YOLOv11 model.
  - Automatically crop detected items, extract their colors, and save the catalog.
- **OWL-ViT Pathway**:
  - Load open-vocabulary detections (`owlvit.json` generated by the `owl_vit` module).
  - Crop detected items from user photos.
  - Extract dominant colors for all crops.
  - Compile the final private wardrobe index `wardrobe.json`.
- Uses a robust HSV-space color database to map hue/saturation/value mean parameters to 26 canonical color labels.

## Running the Pipelines

### OWL-ViT Pipeline
1. Run OWL-ViT detection in the `owl_vit` folder to generate `owlvit.json`.
2. Crop the detections:
   ```bash
   python crop_detections.py
   ```
3. Extract colors from the crops:
   ```bash
   python extract_colors_owlvit.py
   ```
4. Compile the final wardrobe database:
   ```bash
   python build_wardrobe_owlvit.py
   ```
This will generate `data/wardrobe.json`.

### YOLO Pipeline
Run YOLO detection, crop generation, color extraction, and database indexing in one step:
```bash
python build_wardrobe_yolo.py
```
This will run detection on a test photo and save outputs to `data/colors.json`.
