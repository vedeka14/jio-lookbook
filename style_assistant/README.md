# Style Assistant

The interactive web interface for Jio Lookbook, built with Streamlit. 
Provides the user-facing application where users can view their generated wardrobe, upload travel itineraries, and receive personalized outfit recommendations.

## Running the App

To start the UI, you can use the `start_lookbook.bat` shortcut in the root directory, or manually run:

```bash
python -m streamlit run app.py
```
